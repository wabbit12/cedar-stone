# Cedar & Stone (Next.js)

Next.js + React + TypeScript recreation of the Cedar & Stone WordPress demo site.

## Run locally

```bash
cd cedar-stone-next
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy free on Vercel

1. Push this folder to GitHub.
2. Import the repo in [vercel.com](https://vercel.com).
3. Deploy — you get a public URL for your portfolio.

## Pages

- `/` Home
- `/about`
- `/services`
- `/contact` (client-side form demo)
- `/blog` + `/blog/[slug]`
